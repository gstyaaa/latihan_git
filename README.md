# Latihan Deploy - tesGIT

Proyek ini adalah sebuah website statis sederhana yang dibuat untuk tujuan pembelajaran Git, GitHub, dan proses deployment. Website ini menampilkan pesan sapaan interaktif menggunakan JavaScript.

## 🚀 Fitur
- **Layout Responsif:** Menggunakan CSS modern untuk tampilan yang bersih.
- **Interaksi JavaScript:** Tombol uji coba yang memberikan respon saat diklik.
- **Siap Deploy:** Konfigurasi yang kompatibel dengan layanan hosting statis seperti Vercel atau GitHub Pages.

## 🛠️ Teknologi yang Digunakan
- **HTML5:** Struktur konten website.
- **CSS3:** Styling dan tata letak.
- **JavaScript (ES6):** Logika interaktif sederhana.

## 📁 Struktur Folder
- `index.html`: Berkas utama website.
- `style.css`: Berkas desain dan layout.
- `script.js`: Logika interaksi JavaScript.

## 📦 Cara Menjalankan Secara Lokal
1. Clone repositori ini:
   ```bash
   git clone https://github.com/[USERNAME-KAMU]/latihan-git.git
   ```
2. Buka folder proyek.
3. Klik dua kali pada `index.html` atau gunakan ekstensi *Live Server* di VS Code.

## 🌐 Deployment
Proyek ini telah dideploy menggunakan **Vercel**. Setiap perubahan yang di-push ke branch utama akan secara otomatis memperbarui versi live website.
